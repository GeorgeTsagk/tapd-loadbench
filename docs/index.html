The like-for-like backend comparison. uni-tapd and uni2-tapd are federation peers that both sync all assets, so they hold the same content under the same load and differ only in backend. Postgres carries a fixed multi-megabyte catalog baseline, so read the slope, not the offset.

Marginal storage cost of one epoch's work on each backend. Flat is healthy; a rising trend means each unit of work is getting more expensive to store.
